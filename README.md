# Bank Management App

## Overview

A full-stack Bank Management App developed using Java and Spring Boot.
The application provides REST APIs for managing banks, customer accounts,
addresses, deposits, withdrawals, and fund transfers.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- HTML
- CSS
- JavaScript
- Maven

## Features

- Bank management
- Customer account management
- Address management
- Deposit management
- Withdrawal management
- Fund transfers
- CRUD operations
- Account validation
- Search functionality
- Pagination
- Sorting
- Exception handling
- REST APIs
- PostgreSQL database integration

## Project Architecture

The project follows a layered architecture:

- Controller
- Service
- Repository
- Entity
- DTO
- Exception Handling

## Database

PostgreSQL

## How to Run

1. Clone the repository.
2. Open the project in Eclipse.
3. Configure PostgreSQL.
4. Update the database configuration in the application properties.
5. Run the Spring Boot application.
6. Access the REST APIs through the configured server.
